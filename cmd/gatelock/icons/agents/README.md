# Agent icons

Each file is the mark of a coding agent that `internal/caller` tells
apart, which the Activities page shows beside the activities it ran.
Only Claude Code's and Codex's are here; other programs show by name
alone.

The SVGs come from [LobeHub Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg` 1.98.0, MIT), by way of mux: the `-color`
version where there is one. The marks are trademarks of their owners.

`codex.svg` has lost the white rounded square under the mark, which stood
out on dark backgrounds.
